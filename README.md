# Juan Diego Mejia Vargas Portfolio

Modern recruiter-facing portfolio built with React, Vite, TypeScript, and CSS Modules.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## What to customize

- Replace `/public/assets/og-placeholder.svg` with a real OpenGraph preview image.
- Add a personal headshot or tasteful project screenshots if you want richer visuals.
- Update portfolio copy and data when your CV changes.
- Add live source links for private or unavailable projects when you can share them.

## Suggested commits

- `chore: scaffold vite react portfolio`
- `feat: add cv-driven portfolio content`
- `feat: build responsive recruiter portfolio ui`
